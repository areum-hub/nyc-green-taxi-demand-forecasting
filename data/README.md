# Local data (not committed)

Download NYC TLC Green Taxi monthly Trip Record Parquet for Jan 2024-Dec 2025 into `data/raw/`. Use the original TLC names `green_tripdata_YYYY-MM.parquet`. For the full 30-month quality comparison, optionally add 2026 Jan-Jun.

`data/raw/` and `data/processed/` are gitignored. Do not upload bulky raw trip records to GitHub. See [NYC TLC Trip Record Data](https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page).
