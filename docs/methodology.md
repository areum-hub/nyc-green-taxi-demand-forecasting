# 모델 검증 방법론 (Methodology)

이 문서는 **2025년 Expanding Window 4-Fold 독립 재현 실험**의 데이터 처리, 특성 구성, 학습 조건 및 평가 방법을 설명합니다. 프로젝트 배경, 성능 결과와 개인·팀 기여도는 [메인 README](../README.md)를 참고하세요.

> **적용 범위:** 이 저장소의 재현 코드는 2025년 교차검증용입니다. **2026년 상반기 결과는 4Sight 팀 최종모형의 별도 보고 수치**이며, 해당 최종모형의 원본 학습·평가 파이프라인은 여기에 포함되지 않습니다. 따라서 두 평가를 동일한 모델 실험으로 간주하지 않습니다.

## 1. 데이터 전처리 및 예측 대상 구성

### 1-1. 입력 데이터 범위

데이터 출처: [NYC TLC Green Taxi Trip Records](https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page)

- **2025년 독립 재현 실험의 필수 데이터:** 2024년 1월~2025년 12월 월별 Parquet **24개**
- **선택적 품질 집계 데이터:** 2026년 1~6월 Parquet **6개**. 품질 집계에는 포함할 수 있지만 2025년 4-Fold 학습·검증에는 사용하지 않음
- **품질 검토 범위:** 아래 건수는 2024년 1월~2026년 6월 **30개 파일을 모두 사용한 경우**의 집계 ([월별 품질 CSV](../reports/metrics/raw_quality_reproduced.csv))

### 1-2. 기본 승차기록 정제 (`src/prepare_data.py`)

기본 정제는 **승차 시각과 승차지역 코드**만 기준으로 수행합니다. 순서에 따른 제외 건수는 다음과 같습니다.

| 처리 단계 | 적용 조건 | 제외 건수 | 잔여 건수 |
| --- | --- | ---: | ---: |
| 원본 데이터 | 30개 월별 Parquet | — | **1,506,768** |
| 승차 월 검증 | `lpep_pickup_datetime`의 연·월이 해당 파일의 연·월과 일치 | 480 | 1,506,288 |
| 승차지역 검증 | 위 조건 통과 건 중 `PULocationID`가 **1~263** | 4,592 | **1,501,696** |

- 승차 시각은 날짜형으로 변환한 뒤 파일의 연·월과 대조합니다. 변환되지 않는 승차 시각도 연·월 일치 조건을 통과하지 못합니다.
- **4,592건**은 승차 월 검증을 통과한 데이터에서 추가로 제외된 건수이므로, 두 제외 건수는 서로 겹치지 않습니다.
- 이 기본 정제 단계에서는 **`DOLocationID`, 하차 시각, 운행거리, 운임, 소요시간, 평균속도**를 이유로 승차기록을 추가 제외하지 않습니다.
- 기본 정제 결과는 로컬 `data/processed/valid_trips.pkl`에 저장하며, 대용량 중간 파일은 GitHub에 포함하지 않습니다.

### 1-3. 모델 학습용 지역·시간 데이터 구성 (`src/run_4fold_cv.py`)

기본 정제 결과에서 **2024~2025년 기록만** 선택한 뒤, **2024년 승차 건수 상위 20개 지역**을 예측 대상으로 고정합니다. 예측 대상 시각별로 각 지역의 승차 건수를 집계하고, 승차기록이 없는 지역·시간 조합은 **0건**으로 채웁니다.

즉, **기본 정제 후 유효 승차기록 수(1,501,696건)**와 **모델 학습에 사용하는 20개 지역 × 시간 단위의 관측치 수**는 서로 다른 개념입니다. 전자는 30개월 전체 품질 집계이고, 후자는 2024~2025년 데이터로 구성한 예측 패널입니다.

### 1-4. 과거 완료 운행 특성 생성용 추가 조건

다음 조건은 **별도 파생특성을 계산할 때만** 적용합니다. 기본 정제에서 관측 승차 건수(`y`)를 추가로 제거하는 조건이 아닙니다.

| 항목 | 코드상 적용 기준 |
| --- | --- |
| 하차 지역 코드(`DOLocationID`) | 1~263 |
| 운행 소요시간(`dropoff - pickup`) | 1~180분 |
| 운행거리(`trip_distance`) | 0~100마일 |
| 운임(`fare_amount`) | 0~500 |
| 추정 평균속도(`trip_distance / 소요시간`) | 0~100mph |
| 하차 시각 | 유효한 시각이어야 함 |

이 조건을 통과한 운행을 **실제 하차가 완료된 시각(`completed_hour`)** 기준으로 집계합니다. 예측 대상 지역에서 완료된 운행 및 해당 지역으로의 유입량 등을 파생특성으로 활용하고, 시간에 따른 집계값은 `shift(1)`을 적용해 **예측 대상 시간 이전에 완료된 정보만** 사용합니다.

## 2. 시계열 교차검증 설계

**Expanding Window** 방식으로 매 Fold마다 과거 학습 기간을 늘리고, 이후 3개월을 검증합니다.

| Fold | 학습에 포함되는 기간 | 검증 기간 |
| --- | --- | --- |
| 1 | 2024년 1~12월 | 2025년 1~3월 |
| 2 | 2024년 1월~2025년 3월 | 2025년 4~6월 |
| 3 | 2024년 1월~2025년 6월 | 2025년 7~9월 |
| 4 | 2024년 1월~2025년 9월 | 2025년 10~12월 |

- **시간 누수 방지:** 학습 데이터는 검증 시작 시점보다 이전 기록으로 제한합니다. 2026년 데이터는 학습·검증에 사용하지 않습니다.
- **Lag 초기화:** 최대 시차 504시간을 확보하지 못한 초기 관측 구간은 제외합니다.
- **시간대 처리:** 뉴욕 서머타임(DST) 전환일(2024-03-10, 2024-11-03, 2025-03-09, 2025-11-02)을 제외합니다.
- **경계 컬럼:** [Fold별 결과 CSV](../reports/metrics/2025_4fold_model_scores.csv)의 `train_until_exclusive`는 **학습에 포함되지 않는 첫 날짜**입니다. 예를 들어 `2025-04-01`이면 3월 31일까지 학습하고 4월 1일부터 검증합니다.

## 3. 특성 구성 (Feature Engineering)

독립 재현 모델의 입력은 **19개 특성**입니다. 상세 이름은 [실제 학습·평가 코드](../src/run_4fold_cv.py)의 `FEATURES` 목록과 일치합니다.

| 분류 | 특성 | 개수 |
| --- | --- | ---: |
| 지역·달력 정보 | `zone_id`, `hour`, `dow`, `month`, `weekend`, `day_index` | 6 |
| 과거 승차량 | `lag_1`, `lag_24`, `lag_168`, `lag_336`, `lag_504`, `rolling_mean_24`, `rolling_mean_168` | 7 |
| 과거 완료 운행·유입 흐름 | `mean_duration_168h`, `fare_per_hour_168h`, `same_zone_share_168h`, `arrivals_lag1`, `arrivals_mean24`, `net_flow_mean24` | 6 |

**시간 종속 특성의 처리:** 승차량의 Lag·Rolling Mean은 과거 관측치를 사용합니다. 완료 운행 관련 기록은 **하차가 완료된 시간(`completed_hour`)**을 기준으로 집계하고, 목표 시각으로부터 최소 1시간 이전 정보만 사용하도록 `shift(1)`을 적용합니다. 예측 대상 시점의 완료 운행 결과를 입력하는 방식은 허용하지 않습니다.

## 4. 모델과 비교 기준선

**독립 재현 모델:** LightGBM `LGBMRegressor(objective="poisson")`

| 매개변수 | 설정 |
| --- | --- |
| `n_estimators` | 600 |
| `learning_rate` | 0.05 |
| `num_leaves` | 31 |
| `min_child_samples` | 25 |
| `random_state` | 42 |

**비교 기준선(Baseline)**

- **과거 3주 평균:** 예측 대상 시간의 168·336·504시간 전 승차 건수 평균
- **요일·시간대 평균:** **각 Fold의 학습 구간**에서 지역·요일·시간별 실제 승차 건수를 평균해 검증 구간에 적용

모델 및 기준선은 같은 Fold의 동일한 지역·시간 관측값을 대상으로 평가합니다.

## 5. 평가 지표와 집계 방식

| 지표 | 계산 대상 및 의미 | 개선 방향 |
| --- | --- | --- |
| **MAE** | 전체 검증 지역·시간의 실제 건수와 예측 건수 간 절대오차 평균 | 낮을수록 좋음 |
| **RMSE** | 전체 검증 지역·시간의 제곱오차 평균에 제곱근을 취한 값 | 낮을수록 좋음 |
| **TVD** | 시간마다 20개 지역의 실제·예측 승차 비율 분포 차이(`0.5 × 절대 비율 차이의 합`)를 계산한 뒤 시간 평균 | 낮을수록 좋음 |
| **Top-5 승차 포착 비율** | 예측 승차 비율이 높은 상위 5개 지역에서 발생한 실제 승차가, 해당 시간 전체 실제 승차에서 차지하는 비율의 시간 평균 | 높을수록 좋음 |

TVD와 Top-5는 **선정된 20개 지역에서 실제 승차가 1건 이상인 시간**만 집계합니다. Fold 요약의 `*_sd`는 **4개 Fold 간 표본 표준편차**이며, 신뢰구간이나 예측구간이 아닙니다.

## 6. 재현 범위 및 해석상 유의사항

- **재현 가능한 부분:** 공개된 [전처리 코드](../src/prepare_data.py), [4-Fold 학습·평가 코드](../src/run_4fold_cv.py), [시각화 코드](../src/visualize_results.py)를 사용한 **2025년 독립 재현 실험**
- **별도 출처:** [2026년 평가 CSV](../reports/metrics/2026_team_holdout_summary.csv)는 **팀 최종모형 보고 결과**입니다. 2025년 코드와 동일한 설정·특성·모델 선택 절차를 거쳤다고 검증된 것은 아닙니다.
- **분석 대상의 한계:** TLC에는 *완료된 승차*가 기록되므로 **미충족 승차 요청, 실제 가용 차량, 재배치 비용**을 이 데이터만으로 알 수 없습니다. 차량 배치와 Coverage Proxy는 **가상 의사결정 시나리오**이지 실현 영업 성과가 아닙니다.
